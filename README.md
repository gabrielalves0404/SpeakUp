# SpeakUp
Um aplicativo onde você treina o seu inglês!
O jogo mostra uma palavra em português, você fala a tradução em inglês e o programa grava sua voz, reconhece a fala e compara com a resposta certa.
Exemplo:
  ┌────────────────────────────────────────────┐
  │  Como se diz  ➜  ANIVERSÁRIO               │
  │  em Inglês 🇺🇸                             │
  └────────────────────────────────────────────┘
  🎙️  Estou ouvindo... fale quando quiser!
  👂 Você disse: "birthday"
  📊 Similaridade: 100%
  🎉 Correto!

  Instale a biblioteca:
    pip install sounddevice scipy numpy SpeechRecognition googletrans

📋Requisitos:
  - Um microfone
  - Conexão com a Internet
